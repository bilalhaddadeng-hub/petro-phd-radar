# 🛢️ PetroPhD Radar Bot (رادار دكتوراه هندسة البترول والطاقة الجوفية)

نظام آلي متقدم مخصص للبحث اليومي والتنبيه الذكي عن أحدث فرص الدكتوراه المفتوحة في **هندسة البترول (Petroleum Engineering)، محاكاة المكامن (Reservoir Engineering)، الحفر والإنتاج، وتخزين الكربون (CCUS) والهيدروجين**.

تمت مواءمة محرك التقييم داخل البوت خصيصاً للطلبة **الجزائريين الدارسين في إيطاليا** (حاملي ماستر Laurea Magistrale بنظام ECTS الأوروبي).

---

## 🎯 مميزات النظام ومصادر البيانات المعمقة

1. **المنح الحكومية الوطنية (Government Scholarships):**
   - منح **PNRR / MUR** الإيطالية بشراكة شركات الطاقة مثل **ENI**.
   - منحة **KFUPM** (جامعة الملك فهد للبترول والمعادن - كلية البترول والعلوم الجيولوجية CPG).
   - منحة الحكومة المجرية **Stipendium Hungaricum** لجامعة مسكولك.
2. **المعاهد ومراكز الأبحاث الدولية (Research Institutes):**
   - معهد **IFP Energies nouvelles (IFPEN)** الفرنسي.
   - مشاريع الاتحاد الأوروبي ومراكز **Helmholtz** و **EURAXESS**.
3. **فرص ومشاريع الأساتذة المباشرة (Professor & Lab Funded Positions):**
   - مشاريع المخابر المستقلة (Montanuniversität Leoben النمسا، Heriot-Watt بريطانيا، UiS النرويج).
4. **تتبع دورة حياة الفرصة:**
   - فرصة جديدة فتحت اليوم (`⚡ NEW`).
   - اقتراب موعد الإغلاق النهائي بأقل من 7 أيام (`⏳ CLOSING SOON`).
   - تحديث في المواعيد أو الشروط (`🔄 UPDATED`).

---

## 📋 الأوامر التفاعلية في تيليجرام

- `/today` : عرض الفرص الجديدة التي فُتحت اليوم ولم تشاهدها بعد.
- `/closing_soon` : تنبيه بالفرص التي تغلق خلال الأسبوع الحالي.
- `/all_open` : استعراض كافة الفرص المفتوحة حالياً في قاعدة البيانات.
- `/professors` : فلترة الفرص الممولة مباشرة من أساتذة ومشاريع مخابر.
- `/institutes` : فلترة فرص المعاهد مثل IFPEN و EURAXESS.
- `/governments` : فلترة المنح الحكومية المفتوحة (PNRR, KFUPM, إلخ).
- `/search <كلمة>` : بحث مخصص (مثلاً: `/search CCUS` أو `/search Italy`).
- `/scan_now` : تشغيل زاحف الويب لتحديث قاعدة البيانات فوراً.

## 🚀 طريقة التثبيت والتشغيل السريع

### 1. تثبيت المتطلبات
```bash
cd C:\Users\admin\.gemini\antigravity\scratch\petro_phd_radar_bot
pip install -r requirements.txt
```

### 2. إعداد المتغيرات
قم بإنشاء ملف `.env` أو تعديل `config.py`:
```env
TELEGRAM_BOT_TOKEN="توكن البوت من BotFather"
TELEGRAM_CHAT_ID="معرف حسابك على تيليجرام"
```

### 3. تشغيل البوت
```bash
python bot.py
```
سيبدأ البوت فوراً بالاستماع، وإرسال تقرير صباحي مجدول يومياً في تمام الساعة 08:30 صباحاً.
